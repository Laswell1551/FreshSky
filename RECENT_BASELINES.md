# Recent baseline provenance and matched adapters

Four literature methods are implemented and evaluated, rather than only cited. All implementation here is independently written from the papers; no author repository was located in the focused search on 2026-10-13. This statement concerns the search, not a claim that no code exists.

## Common information and outcomes

All decisions receive current ages, event weights, prescribed power and the same appropriate information. Full-information controllers receive threshold feasibility, whereas feedback methods receive attempted ACK/NACK only. Wang and Lya-PPO use the same calibrated transition and delivery likelihoods as FreshSky-B; WiSwarm retains its response-window estimator; Tripathi uses its stationary Bernoulli reference. Hidden truth is never passed into a feedback controller. Potential deliveries, events, synthetic geometry and cached urban routes are shared with the existing controls.

None of the three literature index priorities is given a FreshSky energy-price term. This preserves the source policies' distinguishing decision rules. Unguarded runs report the resulting individual power; common 900/720-mJ full-information and 148/118.4-mJ feedback reserves provide matched finite-energy comparisons. Urban replay uses the same 272-mJ/source reserve, routes, prefix calibration and scoring suffix. Lower age with power above the individual target is reported as such.

## Learning protocol

Full-information and feedback models are trained separately. Each has five independent initialization/action-sampling seeds (20000–20004), with 16 independent training traces (geometry/event/delivery seeds 1000–1015); no evaluation or calibration trace is used in training. Feedback training mixes blocked dwell 2/8/20. Each model receives 1,024,000 transitions (500 updates, 16 environments, 128 slots per rollout). PPO uses two 32-unit tanh layers, four epochs per update, minibatches of 256, learning rate 0.0003, discount 0.99, generalized advantage parameter 0.95, clip 0.2, entropy coefficient 0.01 and gradient norm cap 0.5. Actor features are current normalized age, importance, reliability, log power, debt-cost product, expected weighted age reduction, age cap and budget. A pooled state supplies the value and idle heads. Three categorical grants are sampled without replacement, allowing repeated idle tokens.

Checkpoints after updates 250/375/500 are selected using disjoint seeds 50/51. Full calibration uses 1500-slot missions; feedback calibration covers all three dwell values. Select minimum weighted age among checkpoints meeting every calibration source's scored power target; if none meets the target, record that fact and select minimum excess followed by age. Selection is frozen before evaluation on seeds 0–4. Evaluation seed i uses independent training model i and greedy masked actions. NumPy-exported checkpoints reproduce the trained actor/idle network without a Torch runtime.

## Reproduction and certificates

- python scripts/build_belief_indices.py builds/caches the dynamic-programming approximations.
- python scripts/train_recent_suite.py trains ten CPU models; requires requirements-learning.txt.
- python scripts/recent_baselines.py selects checkpoints on calibration traces and regenerates the new comparisons from supplied checkpoints.
- python scripts/check_recent_baselines.py validates numerical sources, training independence, selection, common energy guards, source-equation fixtures and single-arm certificates.

The existing controls and their CSVs are retained. recent_stationary, recent_shift, recent_battery, recent_belief, recent_partial_battery and recent_city files contain the additions; each has seed records and summaries. Urban standard deviation remains across five geometry means. Learning histories, all three checkpoints per model, selection records and single-arm indices are released with the experiment code.
